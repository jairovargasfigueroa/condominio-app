## Instalación

1. Clona el repositorio:
	```sh
	git clone https://tu-repo-url.git
	cd my_flutter_app
	```

2. Instala las dependencias:
	```sh
	flutter pub get
	```

## Ejecución

Para correr la app en modo desarrollo:
```sh
flutter run
```

## Ejecutar tests

Para correr los tests:
```sh
flutter test
```
